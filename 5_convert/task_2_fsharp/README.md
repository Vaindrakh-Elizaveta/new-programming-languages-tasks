# Задача 5.2. CSV → JSON

**Язык программирования:** F#

Дан CSV-файл, первая строка которого содержит названия полей, а остальные строки — значения. Преобразовать данные в массив объектов в формате JSON и сохранить результат в отдельный файл.

Разрешается самостоятельно сформировать JSON без специализированных библиотек, но результат должен быть корректным JSON и содержать экранирование строковых значений.
