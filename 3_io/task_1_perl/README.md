# Задача 3.1. Статистика введённых чисел

**Язык программирования:** Perl

Пользователь вводит с клавиатуры последовательность чисел. После окончания ввода программа должна вывести количество чисел, их сумму, среднее значение, минимальный и максимальный элементы.

Способ обозначения окончания ввода и поведение при некорректном вводе должны быть описаны в программе.
