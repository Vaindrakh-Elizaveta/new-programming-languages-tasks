# Задача 5.1. CSV → TSV

**Язык программирования:** Swift

Дан текстовый файл, содержащий таблицу, в которой значения разделены запятыми. Преобразовать данные в формат TSV, где значения разделяются символами табуляции, и сохранить результат в новый файл.

Учесть поля, заключённые в кавычки, и экранирование кавычек, чтобы запятые внутри поля не стали разделителями.
