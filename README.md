# Новые языки программирования

Набор из 20 постановок задач для индивидуальной работы: пять тем, по четыре задачи в каждой. Для каждой задачи выбран отдельный язык программирования. В репозитории находятся только постановки задач и распределение языков; решений нет.

## Структура

| Тема | Каталог | Задачи и языки |
|---|---|---|
| Многопоточность | `1_threads/` | 1.1 Kotlin, 1.2 Rust, 1.3 Elixir, 1.4 Ruby |
| Алгоритмические задачи | `2_algorithms/` | 2.1 Haskell, 2.2 Scheme, 2.3 Zig, 2.4 Scala |
| Ввод/вывод в консоль и файл | `3_io/` | 3.1 Perl, 3.2 Lua, 3.3 Nim, 3.4 D |
| Клиент-серверное взаимодействие | `4_client_server/` | 4.1 Erlang, 4.2 Julia, 4.3 OCaml, 4.4 Groovy |
| Конвертация данных | `5_convert/` | 5.1 Swift, 5.2 F#, 5.3 Clojure, 5.4 Lisp |

Каждый каталог задачи имеет вид `task_<номер>_<язык>/README.md`.
