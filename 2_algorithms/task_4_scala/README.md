# Задача 2.4. Поиск кратчайшего пути в таблице

**Язык программирования:** Scala

Дана прямоугольная таблица, каждая клетка которой содержит положительное число — стоимость прохождения через неё. Из левой верхней клетки разрешено двигаться только вправо или вниз. Найти минимальную стоимость пути до правой нижней клетки и вывести эту стоимость.

В качестве дополнительного результата можно вывести последовательность клеток найденного пути.
