# Задача 2.1. Рекурсивный обход лабиринта

**Язык программирования:** Haskell

Дан прямоугольный лабиринт, состоящий из свободных и заблокированных клеток. Необходимо рекурсивно определить, существует ли путь из заданной начальной клетки в заданную конечную клетку. Если путь существует, вывести один из найденных путей.

При обходе нельзя повторно посещать одну и ту же клетку. Входные данные должны содержать размеры лабиринта, его карту и координаты начала и конца.
