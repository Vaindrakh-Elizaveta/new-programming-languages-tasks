# Задача 3.2. Анализ текстового файла

**Язык программирования:** Lua

Прочитать текстовый файл и определить количество строк, слов и символов в нём. Полученную статистику вывести в консоль.

Необходимо явно зафиксировать правила подсчёта слов и символов, включая обработку пробелов, знаков препинания и переводов строк.
