# Задача 4.1. Эхо-сервер

**Язык программирования:** Erlang

Разработать сервер, принимающий текстовое сообщение от клиента. Сервер должен отправить клиенту полученное сообщение обратно. Клиент выводит ответ сервера в консоль.

Описать формат обмена сообщениями, номер порта и способ завершения соединения. Сервер должен корректно обработать отключение клиента.
