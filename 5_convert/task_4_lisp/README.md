# Задача 5.4. Десятичные числа → двоичная и шестнадцатеричная запись

**Язык программирования:** Lisp

Дан текстовый файл с целыми десятичными числами. Для каждого числа получить его представление в двоичной и шестнадцатеричной системах счисления. Результат записать в новый текстовый файл в виде:

`десятичное_число;двоичное_число;шестнадцатеричное_число`

Задать правило обработки отрицательных чисел и некорректных строк входного файла.
