# Задача 2.3. Проверка правильности скобочной последовательности

**Язык программирования:** Zig

Дана строка, содержащая круглые `()`, квадратные `[]` и фигурные `{}` скобки. Определить, является ли последовательность скобок правильной: каждая открывающая скобка должна быть закрыта скобкой того же типа, а вложенные скобки должны закрываться в обратном порядке открытия.

Игнорировать все символы строки, кроме шести видов скобок, либо явно описать выбранное правило обработки остальных символов.
