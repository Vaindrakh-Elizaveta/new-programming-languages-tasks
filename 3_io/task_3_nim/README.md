# Задача 3.3. Фильтрация данных из файла

**Язык программирования:** Nim

В текстовом файле записаны целые числа, по одному числу в строке. Прочитать файл и записать в два новых файла отдельно чётные и нечётные числа. В консоль вывести количество чисел, записанных в каждый файл.

Предусмотреть обработку пустых строк и строк, не содержащих корректное целое число.
