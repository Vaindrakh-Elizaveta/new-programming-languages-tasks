# Задача 1.4. Общий банковский счёт

**Язык программирования:** Ruby

Создать модель банковского счёта с начальным балансом. Несколько потоков одновременно выполняют операции пополнения и снятия средств. Обеспечить синхронизацию доступа к общему балансу так, чтобы избежать некорректного изменения данных.

В конце вывести итоговый баланс и количество успешно выполненных операций. Снятие суммы, превышающей доступный баланс, считать неуспешным.
