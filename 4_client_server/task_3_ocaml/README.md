# Задача 4.3. Сервер проверки числа

**Язык программирования:** OCaml

Клиент отправляет серверу целое число. Сервер определяет, является ли оно простым, чётным или нечётным, и возвращает клиенту результат проверки.

Результат должен однозначно описывать все свойства числа. Для чисел, меньших двух, отдельно определить ответ о простоте.
