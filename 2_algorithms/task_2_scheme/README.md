# Задача 2.2. Рекурсивная генерация перестановок

**Язык программирования:** Scheme

Дана строка, состоящая из различных символов. С помощью рекурсии получить все возможные перестановки символов этой строки и вывести их на экран.

Каждая перестановка должна быть выведена один раз. Для пустой строки предусмотреть корректный результат.
