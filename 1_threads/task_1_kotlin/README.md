# Задача 1.1. Параллельное вычисление суммы массива

**Язык программирования:** Kotlin

Сгенерировать или ввести массив из `N` целых чисел. Разделить массив на несколько частей и вычислить сумму элементов каждой части в отдельном потоке. После завершения работы всех потоков вывести общую сумму элементов массива.

Решение должно корректно обрабатывать случай, когда длина массива не делится на число потоков.
