# Задача 1.3. Многопоточный подсчёт частот чисел

**Язык программирования:** Elixir

Дан массив целых чисел. Разделить массив между несколькими потоками. Каждый поток подсчитывает количество вхождений чисел в своей части массива. После завершения потоков объединить результаты и вывести частоту каждого встречающегося числа.

Результат вывести в определённом порядке, например по возрастанию числа.
