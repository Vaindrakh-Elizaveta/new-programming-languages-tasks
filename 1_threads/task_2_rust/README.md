# Задача 1.2. Параллельный поиск минимального и максимального элементов

**Язык программирования:** Rust

Дан массив из `N` чисел. Разделить массив на несколько участков. Каждый поток должен найти минимальный и максимальный элементы своего участка. После завершения потоков определить глобальные минимум и максимум массива.

Для пустого массива предусмотреть понятное сообщение об ошибке или отдельный результат.
