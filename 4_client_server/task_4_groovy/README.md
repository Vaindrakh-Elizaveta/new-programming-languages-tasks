# Задача 4.4. Простое сетевое хранилище

**Язык программирования:** Groovy

Сервер хранит пары вида «ключ — значение». Клиент может отправлять команды для добавления новой пары, получения значения по ключу и удаления пары. Сервер выполняет команду и возвращает клиенту результат операции.

Определить текстовый протокол команд и ответы для случаев отсутствующего ключа, повторного добавления и неизвестной команды.
