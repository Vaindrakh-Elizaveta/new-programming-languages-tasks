# Задача 5.3. JSON → CSV

**Язык программирования:** Clojure

Дан файл в упрощённом формате JSON, содержащий массив однотипных объектов с одинаковым набором простых полей. Преобразовать эти данные в CSV-файл: названия полей записать в первую строку, значения объектов — в последующие строки.

При записи CSV корректно экранировать значения, содержащие запятые, кавычки или переводы строк.
