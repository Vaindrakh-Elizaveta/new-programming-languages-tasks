# Задача 3.4. Таблица студентов

**Язык программирования:** D

Пользователь вводит в консоли сведения о студентах: имя и оценку. Сохранить введённые данные в текстовый файл. Затем прочитать файл, вычислить среднюю оценку и вывести список студентов, имеющих оценку выше средней.

Задать допустимый диапазон оценок и предусмотреть проверку вводимых данных.
